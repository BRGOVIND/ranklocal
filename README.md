# RankLocal

Free, local Windows editor for ranked vertical Shorts. No AI, account, or voiceover.

## Start

Double-click `start.bat`. First run installs Pillow and a bundled FFmpeg binary. Later runs work offline. Open `http://127.0.0.1:8765` if browser does not open automatically.

Drop local MP4/MOV/WebM/M4V/MKV files into the app, set title and rank labels, then export a 1080×1920 MP4. Clips import at full length. Open **Trim manually** on a clip only when you want to set its start or end. Drag the divider between editor and preview to resize them. Choose title font, size, and colors in **Title style**. Projects save automatically in this browser. Uploaded media and exports remain in `data/` beside this app. Keep that folder if you want to reuse saved projects.

Use **New video** for the next post. It clears current clips and deletes their uploaded copies while keeping your title and finished exports. If your browser cannot play a source format, the app makes a smaller local preview; export still uses the original file.

Each clip has its own **Sound on / Muted** switch. Add one local MP3, WAV, M4A, AAC, OGG, or FLAC file in the **Audio** section for music or other sound across the whole video. Adjust its volume; short audio loops to the video's length. Clip sound and added audio mix together unless that clip is muted. Files without clip audio get silence. No voice generation or online clip downloads.

Use **Shuffle order** to change playback order while each clip keeps its rank number and label. For an exact sequence, drag rows or use the arrow buttons. The **Playback** line shows the order that will export.

Use source footage you have rights to reuse.
